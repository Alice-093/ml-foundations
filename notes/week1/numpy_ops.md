# NumPy矩阵运算与广播

## 1.矩阵的逐元素运算 *
数学上对应位置相乘：Cij = Aik * Bkj
```python
A = np.array([[1, 2], [3, 4]])  # shape (2,2)
B = np.array([[5, 6], [7, 8]])  # shape (2,2)
C = A * B                       # shape (2,2)，每个对应位置乘起来
```
Shape 规则：必须完全相同
## 2.矩阵乘法 @
相当于数学上的行乘列求和
```python
A = np.array([[1, 2, 3], [4, 5, 6]])   # shape (2, 3) —— 2行3列
B = np.array([[1, 2], [3, 4], [5, 6]]) # shape (3, 2) —— 3行2列
C = A @ B                              # (2,3) @ (3,2) -> 内标3抵消，保留(2,2)
```
Shape 规则（核心口诀）：“内标抵消，外标保留”，(m,n)@(n,p) -> (m,p)
只有当左矩阵的列数等于右矩阵的行数时，才能乘
## 3.转置 .T
行变列，列变行
Shape 规则:(m,n)->(n,m)
```python
A.T   # 如果A是(2,3)，A.T就是(3,2)
```
## 4.广播规则（Broadcasting）
当两个 Shape 不同的数组做运算时，NumPy 会“自动补齐”。
规则（从右往左对齐）：
从最右边的维度开始比较。
如果维度相等，或其中一个为 1，就可以广播。
缺失的维度视为 1。
例如
```python
#标量 + 矩阵（最基础的广播）
A = np.array([[1, 2, 3], 
              [4, 5, 6]])  # Shape: (2, 3)
b = 10                     # Shape: () 即 0 维标量
C = A + b
#标量 10 被自动复制到A的每一个位置，每个位置上都加上了10，结果 Shape 是 (2, 3)。

#一维数组 + 二维矩阵（行方向广播）
A = np.array([[1, 2, 3], 
              [4, 5, 6]])  # Shape: (2, 3)
b = np.array([10, 20, 30]) # Shape: (3,)
C = A + b
#右对齐：A 的形状是 (2, 3)，b 的形状是 (3,) （左边少一位，视为 1，即 (1, 3)）
#遇 1 补齐：b 沿着第 0 轴（行）“复制”了 2 份，变成 (2, 3)，并对应相加，即A矩阵第一行分别对应加上B数组的元素

#列向量 + 二维矩阵（列方向广播）
A = np.array([[1, 2, 3], 
              [4, 5, 6]])  # Shape: (2, 3)
b = np.array([[10], 
              [20]])       # Shape: (2, 1) —— 注意这里必须是二维，不能是 (2,)
C = A + b
#右对齐：A 的形状是 (2, 3)b 的形状是 (2, 1) 遇 1 补齐：最右边那位，b 是 1，A 是 3。所以 b 沿着第 1 轴（列）“复#制” 3 份，变成 (2, 3)：同样对应相加：
```

## 5. 向量化与欧氏距离

两个三维向量 v1 和 v2 的欧氏距离为：

distance = sqrt(sum((v1 - v2) ** 2))

NumPy 可以通过数组减法、平方、求和和开平方直接完成计算，不需要逐元素编写 for 循环。

## 6. 今日总结

矩阵运算前先检查输入 shape。逐元素运算、矩阵乘法、转置和广播具有不同的规则。每次运算后通过 .shape 检查实际输出，并与预期结果比较。
